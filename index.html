How to use

  1. Place the phone securely side-on at the finish line, across the running path. Keep it out of the runner's path. Use the rear camera and good daylight.
  2. Line up the green stripe with where the runner will cross. The runner should fill a useful part of the frame at that point, but not obscure the whole view.
  3. Use Test detection and walk through the line. Adjust sensitivity or the stripe width if needed. Keep spectators and moving shadows out of the stripe.
  4. Go to the sprint start, tap Arm & start (or have a helper tap it), and run on the beep. The clock stops when sufficient movement enters the stripe.
  5. Repeat several times using the same camera position, light and settings. Allow the finish stripe to become empty between runs.

Accuracy: This is an experimental training tool, not a certified timing gate. The beep starts the clock, so reaction time is included. Movement detection triggers from the first substantial motion in the stripe, not guaranteed torso crossing. Browser video frame rate, exposure and motion blur limit precision; three decimal places are display formatting, not millisecond accuracy. Compare repeat tests only under matched conditions.

Camera access generally requires HTTPS or localhost. Opening the HTML as a local file may not permit camera use in Chrome; upload this file to a static HTTPS host such as GitHub Pages. The camera stream is processed entirely on your phone. Results are stored in this browser using localStorage.
